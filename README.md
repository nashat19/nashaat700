# InstaRashq — محرك رشق متابعين إنستغرام

أداة إنتاجية كاملة لأتمتة دورة **جمع الأهداف → تصفيتها → متابعتها → إلغاء متابعة غير المتفاعلين**، مبنية على `instagrapi` مع طبقة تحكم صارمة تحاكي السلوك البشري وتقلل خطر الحظر.

## المزايا

- **تسخين تدريجي للحساب**: الحصص تبدأ بـ25% وتصل 100% خلال `warmup_days`، فلا تُحرق الحسابات الجديدة.
- **حصص مزدوجة**: سقف يومي + سقف ساعي لكل إجراء، مع عدّاد مستقل لكل يوم.
- **تمويه بشري**: تأخيرات غاوسية مقيّدة، فترات راحة دورية، نافذة ساعات/أيام نشاط بتوقيت محدد.
- **جمع متعدد المصادر**: متابعو منافس، هاشتاغ، موقع، معجبو/معلّقو منشور — مع درجة أولوية لكل مصدر.
- **تصفية جودة**: عدد متابعين، نسبة متابعة/متابعين، خاص/موثّق/تجاري، صورة بروفايل، حد أدنى للمنشورات، لغة البايو.
- **إلغاء متابعة ذكي**: بعد مهلة دنيا، مع قائمة بيضاء دائمة، واستثناء من يتابعك عكسياً، وخيار `--force`.
- **استئناف كامل**: كل شيء في SQLite (WAL) — أوقف وأكمل دون فقدان الحالة.
- **جلسة آمنة**: صلاحيات `0600` وتشفير Fernet اختياري.
- **دعم بروكسي**: تحليل وتدوير وفحص صحة.
- **فحص جاهزية**: أمر `doctor` يتحقق من الحزم والمسارات والصلاحيات والبروكسي والمنطقة الزمنية.
- **مجدول يومي**: أمر `schedule` يشغّل دورات داخل النوافذ النشطة فقط.
- **تقارير وتصدير**: حالة المخزون، الحصص، أحدث الإجراءات، تصدير CSV/JSON.
